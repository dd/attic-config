# attic-config

Дополнения для личного NAS **attic**, управляемые одной командой `attic`. Каждый твик имеет самостоятельный CLI-скрипт, настройки, документацию и тесты. Общий `attic` находит скрипт по имени твика, запускает отдельный Python-процесс и передаёт ему все оставшиеся аргументы. Команды и параметры разбирает сам твик.

Скачивание репозитория ничего не устанавливает. Твики включаются явно и независимо. Сейчас доступен [avahi-recovery](tweaks/avahi-recovery/README.md): ограниченное восстановление Avahi после падения на TrueNAS 25.10.7. На реальном NAS решение ещё не проверено.


## Commands

Из корня репозитория на NAS:

```sh
./attic list
./attic status
sudo ./attic avahi-recovery install
sudo ./attic avahi-recovery config
sudo ./attic avahi-recovery apply
sudo ./attic avahi-recovery uninstall
```

| Command | Effect |
| --- | --- |
| `list` | Показывает доступные твики, не выполняя их код |
| `status` | Показывает включение для boot и вызывает status каждого твика |
| `boot` | Вызывает boot только включённых твиков; одно задание Post Init |
| `NAME --help` | Показывает справку самого твика |
| `NAME install` | Устанавливает твик и после успеха сохраняет его включение |
| `NAME uninstall` | Отключает твик для boot и запускает его удаление |
| `NAME config` | Вызывает собственную настройку твика |
| `NAME status` | Показывает статус выбранного твика |
| `NAME COMMAND [ARGS...]` | Передаёт произвольную команду и аргументы скрипту твика |

У Avahi есть дополнительная команда `apply`, которая применяет обновлённый код и конфиг включённого твика. Другие твики могут добавлять свои команды без правок диспетчера. Например, будущий модуль индикаторов сможет иметь `attic ugreen-leds brightness 50`; такого модуля сейчас нет.

`list`, `status`, `NAME status` и справку можно запускать на компьютере. Остальные команды через `attic` выполняются от root на NAS из защищённого dataset под `/mnt` и сериализуются общим lock. Это правило распространяется и на дополнительные команды. Проверки конкретной ОС, версии и аргументов принадлежат скрипту твика. Вызов справки, включая `NAME install --help`, никогда не меняет список включения.


## Layout

```text
attic-config/
├── attic                          # общий диспетчер
├── tweaks/
│   └── avahi-recovery/
│       ├── tweak.py               # операции и обработчик сбоя
│       ├── config.json            # рабочие настройки твика
│       ├── README.md
│       └── tests/
├── tests/                         # тесты диспетчера и запуск тестов модулей
├── docs/
└── local/                         # создаётся на NAS, исключён из Git
    └── enabled.json               # включённые твики для этой копии репозитория
```

`tweaks/NAME/config.json` - рабочий конфиг с начальными значениями, который хранится в Git. Изменения через `config` изменяют соответствующий файл в копии на NAS. Перед обновлением копии сохранить локальные настройки и проверить diff. `local/enabled.json` является состоянием конкретной установки: оно не копируется из Git и не включается автоматически при добавлении нового модуля. Сохранять `local/` при обновлении файлов на NAS.


## Deployment

1. Скопировать проверенный репозиторий в защищённый dataset на NAS.
2. Включить нужные твики через `attic NAME install`.
3. Один раз добавить `/usr/bin/python3 /mnt/POOL/admin/attic-config/attic boot` в TrueNAS Post Init.
4. После изменения кода или конфигурации выполнить `attic NAME apply` и проверить `attic NAME status`.

Подробности: [установка и миграция](docs/deployment.md), [контракт модуля](docs/modules.md), [результаты проверок](docs/validation.md).


## Development

Только стандартная библиотека Python 3.10+; дополнительные пакеты не требуются.

```sh
python3 -B -m unittest discover -s tests -v
./attic list
./attic status
git diff --check
```

Общая команда тестирования включает тесты из `tweaks/*/tests`. Тесты не обращаются к NAS и внешним сервисам. Новый модуль добавляется отдельной папкой без изменения диспетчера.


## Repository policy

Целевой приватный репозиторий: [dd/attic-config](https://github.com/dd/attic-config). Не хранить пароли, токены, приватные ключи, TrueNAS configuration exports/secret seed или диагностические журналы с личными данными. Проверять diff перед коммитом: `.gitignore` не заменяет просмотр содержимого.

Будущие дополнения, например индикаторы UGREEN, добавлять независимыми твиками. Модуля для индикаторов пока нет. Автоматического скачивания обновлений при старте NAS нет.
