# ugreen-leds

Индикаторы передней панели UGREEN DX/DXP на TrueNAS. Диск мигает при чтении и записи и горит красным при ошибке ZFS или пропаже, индикатор сети мигает при трафике, питание горит ровно. Модуль ядра не нужен, твик обращается к контроллеру LED напрямую через `/dev/i2c-N`, поэтому обновление TrueNAS ничего не требует пересобирать.

Протокол и таблица слотов взяты из [miskcoo/ugreen_leds_controller](https://github.com/miskcoo/ugreen_leds_controller).


## Usage

```sh
sudo ./attic ugreen-leds install
./attic ugreen-leds status
sudo ./attic ugreen-leds config
sudo ./attic ugreen-leds uninstall
```

`install` загружает `i2c-dev`, определяет модель по DMI, находит шину `SMBus I801` и проверяет, что по адресу `0x3a` отвечает контроллер UGREEN с корректной контрольной суммой для каждого индикатора. Если что-то не совпало, на шину ничего не пишется и твик не устанавливается. Затем создаётся `/run/systemd/system/attic-ugreen-leds.service`, который исчезает при перезагрузке и восстанавливается через `attic boot`.

`status` показывает модель, шину и диск в каждом слоте с серийным номером. По нему удобно проверить маппинг, например запустить `dd if=/dev/sda of=/dev/null bs=1M count=2000` и посмотреть, какой индикатор мигает.


## Models

| Model | Bays | Slot order |
| --- | --- | --- |
| DXP2800 | 2 | ata1-ata2 |
| DX4600, DX4700, DXP4800 (Plus, Pro) | 4 | ata1-ata4 |
| DXP6800 | 6 | ata3-ata6, затем ata1-ata2 |
| DXP8800 | 8 | ata1-ata8 |

Модель определяется по началу `/sys/class/dmi/id/product_name`. Если там пусто или стоит что-то общее, модель задаётся вручную в `model`. Если порядок слотов не совпал, в `slots` можно перечислить серийные номера дисков по слотам, `""` для пустого.


## Settings

| Setting | Default | Meaning |
| --- | --- | --- |
| `model` | `auto` | Модель или автоопределение |
| `slots` | `auto` | Маппинг по ATA-портам или список серийников |
| `activity` | `dark` | `dark` гасит индикатор при I/O (как UGOS), `light` зажигает |
| `interval_ms` | 100 | Период опроса активности, 50-1000 |
| `refresh_seconds` | 30 | Период пересчёта слотов и проверки ZFS, 5-3600 |
| `zfs` | `true` | Красный цвет для дисков с vdev не в `ONLINE` |
| `brightness` | 255 | Яркость всех индикаторов, 1-255 |
| `color`, `fault_color` | белый, красный | Цвета диска |
| `network` | `auto` | Интерфейс маршрута по умолчанию, имя интерфейса или `off` |
| `network_color`, `power_color` | оранжевый, белый | Цвета сети и питания |


## Limits

- Модуль `led-ugreen` не должен быть загружен, иначе адрес занят и install откажет.
- Режим standby и SMART не отслеживаются, о них сообщает сам TrueNAS.
- NVMe-слоты индикаторов не имеют и не учитываются.
- Красный цвет снимается сам, когда vdev вернулся в `ONLINE` или в слот вставлен диск.
- `uninstall` и остановка службы гасят индикаторы дисков и сети, питание остаётся включённым.
